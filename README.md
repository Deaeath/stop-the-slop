# Stop The Slop

Chrome extension that flags AI-slop YouTube channels **as you browse**. Channels
that trip the detector get their name highlighted everywhere it appears —
Shinigami Eyes style — plus a badge on every thumbnail.

![MIT](https://img.shields.io/badge/license-MIT-blue) ![Manifest V3](https://img.shields.io/badge/manifest-v3-green)

## The rule it implements

Three signals, scored 0-100 each. The strongest one sets the score.

**0. YouTube's own "Made with AI" label.** Not a heuristic - the uploader ticked
"altered or synthetic content" when publishing, and YouTube renders it as a badge
on the video. It's in the `next` payload as
`metadataBadgeRenderer{label:"AI: Content was made with AI"}`, so it works for
any video id, not just the one on screen. Scores 90 on its own, which lands in
SLOP once anything else corroborates. Matched narrowly, so a video merely
*titled* "made with AI" won't trigger it.


**1. A comment section that's dead *for a channel that size*.**

The naive version of this rule — flag anything under some flat comments/views
percentage — does not work. Measured against real channels, the distributions
overlap almost perfectly:

| Channel | views | comments | ratio |
| --- | ---: | ---: | ---: |
| MKBHD | 4.3M | 4,153 | 0.096% |
| Codex Heresy *(slop)* | 92k | 85 | 0.092% |
| Veritasium | 8.7M | 5,867 | 0.067% |
| CANON FODDER *(slop)* | 11.6k | 6 | 0.052% |

A flat threshold that catches the slop also catches Veritasium. What actually
separates them is **audience size**: engagement falls as an audience grows, so a
3k-view video from a real creator gets ~1.5% comments while a 5M-view one gets
~0.15%. So the score is based on how many times **below expectation for its own
view count** a video sits. 2x below is normal; 20x below scores 100.

Comments turned off entirely scores 60 — suspicious, but not damning, since
YouTube force-disables comments on kids' content.

**2. Commenters saying it's AI.** Reads the top ~40 comments and counts how many
openly accuse the video (`ai slop`, `sounds like TTS`, `generated by AI`,
`elevenlabs`, `six fingers`, …). Bare mentions of "AI" count for a fraction.

**How they combine.** Neither signal is symmetric — a dead comment section is
damning on its own, and so is a chorus of "this is AI", but the *absence* of
either proves nothing, because most people watching slop never comment to say so.
So the **stronger signal sets the score and the weaker one reinforces it**
(`max + 0.3 x min`). Averaging them lets a quiet comment section wash out a
damning ratio — which, in testing, was exactly what stopped it flagging real slop.

Verdicts: **SLOP** >= 65, **SUSPECT** >= 40, otherwise **CLEAR**. All tunable.

### Measured results

Run against known slop and known-human controls:

| | ratio | score | verdict |
| --- | ---: | ---: | --- |
| Lore & Disorder | 0.038% + AI label | 100 | SLOP |
| CANON FODDER | 0.052% + AI label | 100 | SLOP |
| Codex Heresy | 0.092% | 45 | SUSPECT |
| Veritasium (x2) | 0.128% / 0.067% | 0 | CLEAR |
| MKBHD (x2) | 0.171% / 0.096% | 0 | CLEAR |
| Lofi Girl (x2) | ~0.06% | 48 | SUSPECT — false positive |

Note that on all three slop examples the **AI-language signal contributed
nothing** — commenters were discussing Warhammer lore, not calling out AI. The
ratio did all the work. Don't expect the comment signal to fire often; it's
corroboration, not the primary detector.

## What it looks like

- **Every video on the page gets checked.** As cards scroll into view, each new
  channel is scored in the background. Flagged ones light up without you asking.
- **Channel names get highlighted** wherever they appear — feed bylines, the
  sidebar, search results, video descriptions, comment authors. Red for slop,
  amber for suspect.
- **Thumbnails get a corner badge** with the score, and flagged titles are tinted
  red or amber. Nothing is ever dimmed or hidden - you can always read it.
- **Watch pages** get a badge next to the channel name. Click it for the full
  breakdown: per-signal bars, plain-English notes, and quoted comments as evidence.
- **The popup** shows the current verdict, live scan progress, `Scan channel`
  (samples 6 uploads for a firmer verdict), manual `Mark slop` / `Mark fine`, and
  your whole flagged list.

Manual marks always override the score.

## Install

**From a release:** download `stop-the-slop-<version>.zip`, unzip it, then
`chrome://extensions` → **Developer mode** → **Load unpacked** → pick the folder.

**From source:** clone, then load the repo folder the same way. `node build.mjs`
rebuilds the zip; it has no dependencies.

## How it gets the data

No Google API key, no quota, no account. The content script calls YouTube's own
internal `/youtubei/v1/next` endpoint same-origin from the page you're already
on — the same endpoint the site itself uses — which returns exact view counts,
the exact comment count, and comment text for **any** video id. That's what makes
scoring videos you *aren't* watching possible.

Scanning is deliberately restrained: **one video per new channel**, a 500 ms gap
between requests, a budget of 60 channels per page load, and results cached for a
week. Already-known channels cost nothing. All of it is tunable, and the whole
feed scanner can be switched off.

YouTube can reshape those payloads at any time. Every reader in
[src/innertube.js](src/innertube.js) walks the JSON looking for *shapes* rather
than following hardcoded paths, and each signal degrades to "unknown" instead of
throwing — but if badges stop appearing, that file is where to look.

## Known false positives

The detector is a heuristic. Where it's wrong:

| Case | What happens | Why |
| --- | --- | --- |
| **Music / lofi / ambient** | ~48, SUSPECT | Genuinely low-engagement — people listen without commenting. This is the main unfixed false positive; it stays out of SLOP unless comments corroborate. |
| **Channels about AI** | Handled | Their comments are full of "AI". If the title, description, or channel name is about AI, comment-language scoring is cut to 30%. Without this it flags every AI news channel. |
| **Kids' content** | SUSPECT, not SLOP | YouTube force-disables comments, which is why comments-off alone scores 60. |
| **Shorts** | Skipped entirely | Massive views, few comments. Not auto-scanned and never folded into a channel average. Opt in under Options. |
| **Brand-new videos** | Unknown | Comments lag views in the first hours. Under 1,200 views nothing is scored at all. |

Every badge is that **video's** own score. A channel's verdict is its **worst**
video seen, not its average - averaging let a channel with a blatant 98 read as
"suspect" because its other uploads were quieter, which is exactly backwards.
`Scan channel` samples six uploads to find the worst.

## Keeping it up to date

The extension checks GitHub releases every 6 hours and tells you when a new
version is out — a badge on the toolbar icon, a banner in the popup, and a
desktop notification. Turn it off under Options.

It **notifies** rather than silently replacing itself, because Chromium cannot
hot-swap an extension loaded unpacked. To actually pull the new build:

```powershell
# install or update to the latest release
powershell -ExecutionPolicy Bypass -File tools/update.ps1

# ...and check for updates automatically every day
powershell -ExecutionPolicy Bypass -File tools/update.ps1 -Schedule
```

It installs to `%LOCALAPPDATA%\StopTheSlop\extension` and replaces the contents
in place, so the browser keeps pointing at the same folder. Restart the browser
(or hit Reload on the extension) to apply. Point **Load unpacked** at that
folder rather than anywhere under `dist/`, which the build script wipes.

## Options

Gear icon in the popup. If it's flagging too much, raise **Call it slop at** or
lower the **Dead ratio**. If a phrase keeps turning up on slop you run into, add
it under **Extra accusation patterns** as a regex and it'll count as a direct
accusation.

## Privacy

Everything stays in `chrome.storage.local`. The only network requests go to
youtube.com, from the YouTube tab you already have open. Nothing is sent
anywhere else, and there is no telemetry.
